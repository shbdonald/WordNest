# WordNest · 单词窝

Chrome / Edge（Chromium）浏览器扩展：在网页中双击或划词即可翻译并收录生词，支持离线词典、多用户、单词记忆测试，以及中英释义分源补全。

| | |
|---|---|
| 英文名 | **WordNest** |
| 中文名 | **单词窝** |
| 版本 | `3.0.0` |

---

## 功能概览

### 网页端
- **双击 / 划词翻译**：自动查询并弹出结果，可一键加入生词本
- **自动标记**：已收录单词在页面中显示下划线
- **悬停提示**：显示中文释义、音标、发音按钮与来源
- **词形还原**：结合离线词形映射（如 `expectancies` → `expectancy`）

### 主界面（`main.html`）
- **单词列表**：统计总数 / 已记住 / 未记住；支持按最近、字母、状态等排序
- **单词记忆**：选择题练习；答对可标为已记住；可查看详情
- **多用户**：每位用户独立词库与设置
- **单词详情**：
  - 中文释义、英英释义分栏展示，并标注各自来源
  - 音标与英/美音发音
  - 底部汇总「来源」与 **DeepSeek 补全**（用法/例句，可选）
  - 缺失释义时可「重新获取」

### 查询与词典链路
- **释义顺序**（页面短译）：可测速排序，支持离线 / 有道 / 百度 / Google / MyMemory 等
- **详情 · 中文一主一备**：如离线词典 → 有道词典（主成功即停，失败才用备）
- **详情 · 英文一主一备**：如 Free Dictionary → Datamuse
- 设置中可手动选择主备，也可「自动测速并排序」
- 可选配置：**DeepSeek**（详情补全）、**百度翻译** API

### 离线词典
- **一键下载并安装**：从 ECDICT 官方拉取 `ecdict.csv`，浏览器内自动转换并装入 IndexedDB（含音标与词形映射）
- **手动上传 CSV**：网络不佳时备用
- 词库较大时导入需数分钟，请保持设置页打开

### 其它
- **API 日志**：查看近期词典 / 翻译调用情况
- 数据保存在本地（`chrome.storage` + IndexedDB）

## 安装

推荐加载仓库根目录，或已同步的 **`dist`** 目录。

1. Chrome：`chrome://extensions/` · Edge：`edge://extensions/`
2. 打开「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本仓库根目录（或 `dist`）
4. 固定扩展图标，点击打开主界面或弹窗

更细的操作说明见 [README_USAGE.md](./README_USAGE.md)。

## 快速使用

1. 打开任意英文网页，**双击**或**划选**单词 → 查看翻译 → 保存
2. 再次浏览时，已收录词会自动标记；悬停可看释义与发音
3. 点击扩展图标进入主界面：管理生词、做记忆测试、调整设置
4. 设置 → **离线词典管理** → 「一键下载并安装」（约 63MB，视网络而定）  
   国内若 GitHub 不稳定，请自行下载 [ECDICT Releases](https://github.com/skywind3000/ECDICT/releases) 中的 CSV，再用「手动上传 CSV」
5. 设置 → **查询顺序**：按需测速或手动设定中英主备源

## 设置说明（摘要）

| 区域 | 说明 |
|------|------|
| 查询顺序 | 释义链、详情中英主备、发音源；可测速自动排序 |
| 离线词典 | 一键下载 / 上传 CSV 自动转换装载；可清除、刷新统计 |
| DeepSeek | 填写 API Key 后，在详情底部手动补全用法与例句 |
| 百度翻译 | 填写 APP ID / 密钥后可纳入释义测速与排序 |
| 用户管理 | 多用户；可按用户导出 / 清空词库 |

## 目录结构

```
├── manifest.json          # 扩展清单（WordNest 单词窝 v3.0.0）
├── background.js          # Service Worker：离线词典 IndexedDB、消息转发
├── content.js / .css      # 网页划词、标记、悬停
├── popup.html / .js       # 工具栏弹窗入口
├── main.html / .js        # 主界面：列表 / 记忆 / 设置 / 日志
├── options.html / .js     # 设置逻辑（由主界面懒加载）
├── api-log.html / .js     # API 日志页
├── test.html / .js        # 记忆测试相关脚本
├── dist/                  # 发布副本（可选；与根目录同步）
├── dict_converter.py      # 可选：本地 CSV→JSON 工具
├── README.md
└── README_USAGE.md
```

必需运行文件见 `package_files.txt`。大型 `ecdict.csv` / `offline_dict*.json` 默认不纳入版本库。

## 技术要点

- Manifest V3 · Content Script + Service Worker
- 短译与详情分流；详情中英分源合并缓存
- 大型离线词库存 **IndexedDB**；词形映射独立 object store
- 发音：有道 / Google TTS（可排序）
- 英英：Free Dictionary API、Datamuse；中文详情：离线 ECDICT、有道词典、3325 等

---

## 注意事项

- 多数在线接口需要网络；离线词典装好后，中文短译可优先走本地
- 「一键下载」依赖 GitHub 原始文件地址，国内可能需代理或改用手动上传
- 导入完整 ECDICT 会占用较多内存与磁盘，导入期间勿关闭设置页
- DeepSeek / 百度为可选付费或需申请的服务，未配置不影响基础划词与免费词典链
