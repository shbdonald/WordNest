## 功能介绍

- **双击 / 划词翻译**：网页中双击或选中英文单词即可查询并保存
- **自动标记**：已收录词显示下划线；悬停可见中文、音标、发音与来源
- **词形还原**：配合离线词形映射（如 `expectancies` → `expectancy`）
- **多用户**：每位用户独立生词本与数据
- **单词列表**：统计、排序、标记已记住 / 未记住
- **单词记忆**：选择题练习；答对可标为已记住；可打开详情
- **单词详情**：中文释义与英英释义分栏，各自标注来源；底部为汇总来源与 DeepSeek 补全
- **查询主备**：页面短译可排序；详情为「中文一主一备 + 英文一主一备」
- **离线词典**：一键下载 ECDICT CSV 或手动上传，自动转换并装入 IndexedDB
- **API 日志**：查看近期翻译 / 词典调用

## 安装步骤

1. Chrome 打开 `chrome://extensions/`，或 Edge 打开 `edge://extensions/`
2. 开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本仓库根目录或 `dist` 文件夹
4. 固定工具栏图标；点击图标打开弹窗或主界面

必需文件列表见 `package_files.txt`。

## 基本使用

### 保存单词

1. 在任意网页 **双击** 英文单词，或 **划选** 单词  
2. 弹出结果后点击保存，加入当前用户的生词本  

### 查看标记与悬停

- 已保存词会在页面上自动标记  
- 鼠标悬停可看：中文释义、音标、英/美音按钮、来源信息  

### 发音

- 悬停提示框或单词详情中点击 🔊 英 / 美  
- 发音源可在设置「查询顺序 → 发音」中调整（有道 / Google TTS 等）

## 主界面

点击扩展图标进入主界面（`main.html`），顶部导航：

| Tab | 作用 |
|-----|------|
| 单词列表 | 浏览、排序、查看详情、管理记住状态 |
| 单词记忆 | 选择题练习；答错/暂停时可看详情 |
| 设置 | 查询顺序、离线词典、DeepSeek、百度、用户管理 |
| API 日志 | 查看接口调用记录 |

### 单词详情

打开某个词的详情后，大致顺序为：

1. 音标与发音  
2. 用法（若有）  
3. **中文释义**（带来源标签）  
4. **英英释义**（带来源标签）  
5. 底部 **来源汇总**  
6. 底部 **DeepSeek 补全**（需先在设置填写 API Key）  

若中文或英英缺失，可点「重新获取释义」。

## 设置说明

### 查询顺序

- **释义顺序**：页面短译链路（离线 / 有道 / 百度 / Google / MyMemory 等），可用 ↑↓ 调整  
- **详情 · 中文（一主一备）**：如离线词典、有道词典、3325；主源成功即停  
- **详情 · 英文（一主一备）**：如 Free Dictionary、Datamuse；主源成功即停  
- **发音顺序**：有道发音 / Google 发音  

按钮：

- **自动测速并排序**：按延迟重排释义/发音，并自动选定详情中英主备  
- **仅刷新状态**：只更新右侧状态，不改顺序  
- **恢复默认顺序**：回到默认主备与链路  

### DeepSeek API

1. 在设置中填写 API Key（自动保存）  
2. 可点「测试连接」  
3. 在单词详情 **最下方** 点击「用 DeepSeek 补全用法/例句」  
4. 结果会缓存；未配置时不影响免费词典链  

### 百度翻译 API

填写 APP ID 与密钥后自动保存；测速时若已配置会纳入释义排序。  
申请：[百度翻译开放平台](https://fanyi-api.baidu.com/)

### 用户管理

- 主界面顶部可切换 / 添加用户  
- 设置中可按用户导出或清空词库；删除用户会删除其全部单词

## 离线词典

进入：主界面 → **设置** → **离线词典管理**

### 一键下载并安装（推荐）

1. 点击「一键下载并安装」  
2. 自动从 ECDICT 拉取 `ecdict.csv`（约 63MB）  
3. 浏览器内转换 JSON，并写入 IndexedDB（含音标与词形映射）  
4. 查看「当前词库统计」确认单词数与词形映射数  

国内若 GitHub 不稳定，下载可能失败，请改用手动上传。

### 手动上传 CSV

1. 从 [ECDICT Releases](https://github.com/skywind3000/ECDICT/releases) 取得 `ecdict.csv`  
2. 点击「手动上传 CSV」并选择文件  
3. 等待转换与装载完成（勿关闭页面）  

### 清除 / 刷新

- **清除词典**：清空自定义离线词库  
- **刷新统计**：重新读取 IndexedDB 统计  

说明：完整 ECDICT 体积大，导入可能需数分钟，请保持网络与页面稳定。

## 常见问题

### 双击没有反应？

- 确认扩展已启用，并刷新当前网页  
- 部分特殊页面（如浏览器内部页、部分 PDF 查看器）可能无法注入脚本  

### 没有音标或中文很少？

- 先安装离线词典，并将详情中文主源设为「离线词典」  
- 打开详情点「重新获取释义」  
- 词形变化词依赖词形映射表（一键/CSV 安装时会自动生成）  

### 一键下载失败？

- 多为无法访问 `raw.githubusercontent.com`  
- 改用「手动上传 CSV」，或开启代理后再试一键下载  

### 导入很慢 / 页面卡住？

- 大词库属正常，请等待状态提示更新  
- 关闭其它占用内存的标签页后重试  
- 不要在导入中途关闭设置页或重新加载扩展  

### 发音没有声音？

- 检查网络与浏览器是否允许自动播放音频  
- 在设置中切换发音主备源后重试  

### 标记不显示？

- 刷新网页；动态站点可稍等内容加载后再浏览  
- 确认当前用户下确实已保存该词

## 注意事项

1. **本地数据**：生词与词典缓存在本机；清除浏览器数据可能导致丢失，请定期在用户管理中导出备份  
2. **隐私**：词库不主动上传；使用在线翻译/词典时，查询词会发往对应服务；纯离线短译可不依赖外网  
3. **兼容性**：Chrome / Edge 较新版本（Manifest V3）；不支持 Firefox 扩展格式  
4. **可选服务**：DeepSeek、百度需自行申请；未配置时仍可使用免费链路与离线词典
